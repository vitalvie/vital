# Workflow

- **Default branch**: `develop`
- Never commit directly on `develop` or `main`
- Always create a feature branch from `develop`
- PR back to `develop` with squash merge
- PR body is only `## Summary` (1–3 bullets) and `## Test plan`
- Versions start at `0.1.0`. See `docs/releases.mdx`
- Branch naming: see `branches.md`
