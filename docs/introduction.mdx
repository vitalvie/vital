Vital is a **voice-first health assistant**. Ask *"How am I doing today?"* and it answers out loud, using your health data compared to your own baseline.

It's a hackathon demo, built for the [Alan × Mistral AI Health Hack](https://luma.com/t7rspaka). It runs in the browser, with mocked Apple HealthKit data.

## Tech stack

| Layer | Technology |
|-------|-----------|
| Web app | TanStack Start, React, TypeScript, Tailwind CSS |
| Server | TanStack Start server functions |
| AI | Mistral chat completions API |
| Voice | Mistral Voxtral (speech-to-text and text-to-speech) |
| Health data | Mocked, shaped like Apple HealthKit |
| Docs | Mintlify |

<Warning>
  Vital is not a medical device and never gives a diagnosis. For health concerns, talk to a healthcare professional.
</Warning>
