Vital's interface borrows its palette and type from [alan.com](https://alan.com) and its layout from modern voice assistants: one glowing orb, generous whitespace, and very little chrome.

## Principles

1. **Voice first.** The giant watch, and the orb on its screen, is the main control. Everything else supports it.
2. **One screen, one task.** Watch on one side, conversation and data on the other. No extra panels.
3. **Calm and soft.** Pastel surfaces, rounded shapes, gentle motion. No harsh borders or pure black.
4. **Honest data.** Always show the user's number next to their usual. Never diagnose.
5. **Smooth, not flashy.** Motion explains state changes and respects `prefers-reduced-motion`.

## Tokens

All tokens live in `apps/web/src/styles.css` under `@theme`, so they work as Tailwind classes (`bg-cream`, `text-heading`, `shadow-soft`). Never hardcode colors in components.

| Token | Hex | Use |
|-------|-----|-----|
| `cream` | `#fffcf5` | Page background |
| `heading` | `#282830` | Titles, key numbers |
| `paragraph` | `#464754` | Body text |
| `caption` | `#656779` | Labels, hints, status |
| `line` | `#dbe2f4` | Input borders |
| `indigo-500` | `#5c59f3` | Primary actions, orb core |
| `indigo-50` / `blue-50` | `#f0f3ff` / `#ebf5ff` | Card gradient |
| `peach` | `#fff3e5` | Floating highlight bubble |
| `pink-50`, `teal-50` | `#ffe7f0`, `#ebfaf9` | Suggestion chips |
| `good` / `warn` / `bad` | `#367940` / `#ff9359` / `#c9202e` | Status, battery fill, cancel button |
| `titanium-light` / `titanium` | `#e4e1db` / `#a8a39b` | Watch case |
| `band` | `#ff6d39` | Watch band |
| `screen` | `#0b0b12` | Watch screen |

### Type

Font: **Alan Sans** from Google Fonts, weights 400, 500 and 700.

| Role | Style |
|------|-------|
| Page title | 32/40, medium, `heading` |
| Answer | `text-xl`, leading 8, `heading` |
| Key number | `text-4xl`, bold, `heading` |
| Body | 16/24, `paragraph` |
| Label, status | `text-sm` or `text-xs`, `caption` |

### Shape, elevation, motion

| Token | Value |
|-------|-------|
| Radius | Cards `rounded-3xl`, tiles `rounded-2xl`, chips and inputs `rounded-full` |
| `shadow-soft` | Resting elevation for bubbles, chips on hover, the ask bar |
| `shadow-brand` | Indigo glow under the orb |
| `ease-smooth` | `cubic-bezier(0.22, 1, 0.36, 1)` for every transition |
| `animate-fade-up` | 500 ms entrance for new text |

## Components

Components live in `apps/web/src/components/`. One file per component, kebab-case filenames.

| Component | File | Role |
|-----------|------|------|
| `Watch` | `watch.tsx` | Apple Watch Ultra-style frame hosting the voice UI: battery, clock, orb, status, level dots, cancel |
| `Orb` | `orb.tsx` | Voice control and state indicator, shown on the watch screen |
| `BodyBatteryCard` | `body-battery-card.tsx` | Level pill, flat battery, score, one-line summary, three contributor tiles |
| `Conversation` | `conversation.tsx` | Chat panel: header with live status, question bubble, answer, ask bar |
| `AskBar` | `ask-bar.tsx` | Suggestion chips and pill-shaped text input, used inside `Conversation` |
| `DemoDataPanel` | `demo-data-panel.tsx` | Preset chips, plus sliders and 14-day bars when "Adjust numbers" is open |
| `Logo` | `logo.tsx` | "vital" wordmark in Alan Sans with Alan's SVG logo, sharp at any size |
| `ReleaseFooter` | `release-footer.tsx` | Latest GitHub release and CI status on main, under the disclaimer |
| Icons | `icons.tsx` | Stroke icons, 2 px, `currentColor`. The GitHub mark is filled |

### Orb states

| Status | Visual | Tap does |
|--------|--------|----------|
| `idle` | Slow breathing, faint halo | Start recording |
| `listening` | Bright halo, scales with live mic volume | Send the recording |
| `thinking` | Fast spinning halo | Nothing |
| `speaking` | Quick pulse, stop icon | Stop playback |

The status line under the orb says what is happening. The red cancel button appears while listening (discards the recording) or speaking (stops playback).

## Layout

`max-w-5xl`, mobile-first. Two columns from `lg`, stacked below in the order intro, watch, battery, conversation. The right column is left-aligned and every card uses `rounded-3xl` with the same padding (`p-4 sm:p-6`/`p-5 sm:p-6`). The watch scales to 80% under `sm` and 70% under 400 px:

```
Header          logo
┌───────────────┬──────────────────────────────────┐
│ Watch         │ Intro (title, one instruction)   │
│               │ Demo data (presets, adjust)      │
│ (sticky,      │ Number sliders (when open)       │
│  spans rows)  │ Body Battery card                │
│               │ Conversation panel               │
└───────────────┴──────────────────────────────────┘
Footer          medical disclaimer
```

## Rules

- Reuse tokens and components before adding new ones. Add a token in `styles.css` rather than a one-off color.
- Keep copy short, friendly, and non-clinical. Suggest a professional when something looks concerning.
- Every interactive element needs a visible focus state and an accessible name.
- Buttons show a pointer cursor; disabled buttons show `not-allowed` (global rule in `styles.css`).
- Check layouts at 360, 768 and 1280 px with no horizontal scroll. Grid tracks use `minmax(0, 1fr)` so content can shrink.
- New motion uses `ease-smooth` and is disabled under `prefers-reduced-motion`.
- No extra UI libraries. Tailwind and plain React only.
