## Requirements

- Node.js 22+
- pnpm 10+
- Python 3.12+ and [uv](https://docs.astral.sh/uv/)
- An [OpenRouter API key](https://openrouter.ai/keys)
- A modern browser. The mic works on `localhost` or HTTPS.

## Run the app

<Steps>
  <Step title="Install">
    ```bash
    pnpm install
    ```
  </Step>
  <Step title="Add your OpenRouter key">
    ```bash
    cp apps/web/.env.example apps/web/.env
    ```
    Then set `OPENROUTER_API_KEY` in `apps/web/.env`. Optionally set `OPENROUTER_MODEL` (defaults to `mistralai/mistral-small-3.2-24b-instruct`). `TYPESAFE_API_KEY` is only for `pnpm eval`, not for the app.
  </Step>
  <Step title="Start">
    ```bash
    pnpm dev
    ```
    This starts the Python API on port 8000 and the web app on port 3000. Open [http://localhost:3000](http://localhost:3000). Tap the watch, or pick a question. The app opens on a well-rested sample day.

    Under the title, pick **Short night**, **Well rested** or **Stressful week**, or click **Adjust numbers** to change last night's sleep, HRV and resting heart rate.

    To demo from another device, expose it over HTTPS so the browser allows the mic, for example with `tailscale serve --bg 3000`.
  </Step>
</Steps>

## Commands

Run from the repo root.

| Command | What it does |
|---------|--------------|
| `pnpm dev` | Start the API on port 8000 and the web app on port 3000 |
| `pnpm build` | Production build of the web app |
| `pnpm check` | Lint and format check (Biome), then type check |
| `pnpm test` | Unit tests (Vitest and pytest) |
| `pnpm eval` | Live guardrail evals. OpenRouter answers, Jev judges (needs both API keys) |
| `pnpm run deploy` | Deploy a tagged release from `main` to Cloudflare Workers |
| `pnpm docs` | Preview these docs locally (Mintlify, runs on Node 22) |
| `pnpm docs:check` | Check the docs for broken links |

## Deploy

The app runs on Cloudflare Workers (free plan). See [Releases](/releases) for versioning, deploy and rollback.

<Tip>
  No microphone or unsupported browser? Use the suggested questions or the text box. The answer is still read aloud.
</Tip>
